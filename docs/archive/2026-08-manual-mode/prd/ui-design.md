# 界面设计：创建小说 → 设定 → 卷纲 → 章纲 → 正文

> UX 调研员（design-ux-researcher）+ UI 设计师（design-ui-designer）联合产出 · 2026-08-10
> 配套：prototype.html（高保真原型）、user-story-map.md（用户故事）

## 1. 设计原则

1. **永远知道下一步**：每屏至少一个明确的下一步入口；阶段完成即出现下一阶段入口。
2. **状态可见**：进度（n/7）、保存（保存中/已保存/失败）、确认（未填/进行中/已确认）三种状态语言全局统一。
3. **允许旁路**：设定未完成也可以先写，不锁死用户。
4. **桌面长时场景**：信息密度适中，正文优先，暖色低刺激。

## 1.1 统一工作台（免费/PRO 体验一致）

**主界面 = 正文工作台**（左侧卷/章树 + 编辑器），创建后直接进入。
- **设定、大纲 = 高级配置**：同一工作台内的可展开入口，免费/PRO 都可进入、不强制。
- **AI 能力按付费状态显隐**：PRO 用户在同一界面看到「AI 生成正文」；免费用户看不到或见 🔒。
- 提示词只在 PRO 的「AI 生成正文」面板内出现（组装 → 可编辑 → 生成），不常驻任何界面。
- 归档为收尾 tab。

## 2. 屏幕设计与交互（UX 研究员视角）

### 屏 1：作品列表 + 创建弹窗
- 列表卡片显示：书名、阶段标签（进行中：设定）、卷/章数、更新时间、「继续创作」主按钮。
- 创建弹窗：书名输入（自动聚焦）→ 回车创建 → 成功后**直接进入正文工作台**（左侧树 + 编辑器）。
- 交互细节：创建成功后 toast"已创建《书名》"；轻提示"可先写正文，设定与大纲是高级配置，随时可补"。

### 屏 2：工作台 · 正文（主界面）
- 布局：顶部「正文」（默认）+「设定」「大纲」高级配置入口 + 归档；左侧卷/章树 + 右侧编辑器。
- 正文树：只显示有正文的章节（含归档状态）；卷/章增删改在树上。
- 编辑器：直接手写、自动保存、字数、版本历史、归档；工具栏有「AI 生成正文」（PRO）。

### 屏 2.5：高级配置 · 设定（可展开）
- 布局：顶部紧凑进度条"设定 n/7"（完成变色）。
- 新增：设定 tab 顶部紧凑进度条"设定 n/7"（完成变色）。
- 左侧树节点状态徽标：未填（灰）/ 进行中（琥珀点）/ 已确认（绿✓）；可后补项带"可后补"小标签。
- 编辑面板：每项表单 + 底部「确认完成」按钮；确认成功后节点变绿、进度 +1、toast 轻提示。
- 顶部标注"高级配置 · 可选，不影响直接写作"。

**题材节点（含配置）**：
- 选题材：打开题材选择器（分组列表 + 搜索 + 最近使用置顶），选中后节点变为"进行中"。
- 题材配置：编辑面板展开题材配置表单——基调蓝图、禁忌清单、爽点类型、章节类型、节奏规则、故事弧线模板；各区块可折叠，默认值由题材预置模板带入，用户可整体采用或逐项覆盖。
- 高级项标注：配置区顶部注明"高级项，可后补"，不强制填完才能确认题材节点。
- 切换题材：提示"将替换题材相关模板，已填内容保留"，配置覆盖项保留。
- 自定义题材：配置区底部提供"保存为自定义题材"（后续建书可复用）。

### 屏 3：工作台 · 大纲（卷纲 + 章纲 统一视图）
- 布局：左侧一本书的卷/章目录树（卷 → 章，带状态徽标与 ✎/🗑/添加操作），右侧为上下文编辑面板。
- 点「卷」节点 → 右侧显示卷配置：卷摘要、结构模板（三幕式/起承転結/悬疑递进/人物弧线 + 阶段章节分配）、核心冲突、情绪走向、信息差、冲突阶梯、场景卡 + 「保存卷纲」与「去配章纲」。
- 点「章」节点 → 右侧显示章配置：方向输入（卷纲定位/读者缺口/角色状态/钩子盘点）、key_points（感官/动作/判断三锚点）、情绪设计、兑现/埋设钩子、段落拆分、目标字数 + 「保存草稿」/「确认章纲」。
- 缺字段：按钮旁"缺：情感基调、必要变化"（红色小字），点击滚动到对应字段并高亮；已确认章节点绿色 ✓。
- 卷/章 CRUD 都在树上：添加卷（弹窗：卷名/摘要/初始章数）、卷内添加章节（行内输入）、编辑、删除（确认）。

### 屏 5：工作台 · 正文
- 编辑器工具栏：字号（小/中/大）、行距（紧凑/舒适/宽松）、专注模式按钮。
- 专注模式：隐藏左右面板，正文居中 max-w-3xl，Esc 退出。
- 底部状态栏：本章字数 + 保存状态。
- 「AI 生成正文」按钮（付费标识）：点击弹出生成面板——提示词 Markdown（由章纲自动组装、可编辑）→ 确认生成 → 正文流式输出。手动写作全程不出现提示词。

## 3. 视觉规格（UI 设计师视角）

### 3.1 状态色（沿用现有 daisyUI 暖色体系）

| 状态 | 颜色 | 用法 |
| --- | --- | --- |
| 未填 | `base-content/30` + ghost badge | 设定节点、章节 |
| 进行中 | `warning` + 琥珀点 | 编辑中/未确认 |
| 已确认 | `success` + ✓ | 设定项、章纲 |
| 保存中 | `primary` + spinner | 保存按钮 |
| 保存失败 | `error` + 重试 | 保存按钮/提示 |

### 3.2 关键组件规格

- **进度条**：`progress progress-primary h-1.5`，文字"设定 n/7"（`text-xs text-base-content/50`）；7/7 时 `progress-success`。
- **节点徽标**：`badge badge-xs`（ghost/warning/success 三态）。
- **确认主按钮**：`btn btn-primary btn-md`，前置 CheckCircle2（未确认用 Lock）。
- **下一步入口**：`btn btn-outline btn-sm` + ArrowRight，出现在卷创建成功后。
- **缺字段提示**：`text-xs text-error/90` + 字段名 chip（`badge badge-outline badge-error`）。
- **正文排版**：字号 15/17/19px，行距 1.8/2.0/2.2，默认 17px/2.0；`font-serif`（Noto Serif SC）。
- **专注模式**：`max-w-3xl mx-auto`，按钮 `btn btn-ghost btn-sm` + Maximize2/Minimize2。
- **底部状态栏**：`text-xs text-base-content/40`，"本章 xx 字" + 保存状态。

### 3.3 一致性
- 全部 daisyUI 组件，不引入新色板/字体。
- 状态语言与现有 TabProgressButton、OutlineEditor 保存状态机保持一致。
