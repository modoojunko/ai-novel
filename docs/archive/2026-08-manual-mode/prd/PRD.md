## 1. 产品概述

### 1.1 定位
面向中文小说作家的本地桌面创作工具。**免费 = 完整人工写作能力；PRO = 同一界面解锁 AI 能力**，两态体验几乎一致，不搞两套 UI。

### 1.2 核心价值
- 免费用户：建书即写——卷/章树管理 + 直接写正文，**不需要任何前置设定**。
- PRO 用户：同一工作台内获得 AI 生成（设定/卷章高级字段作为 AI 上下文）。

### 1.3 目标用户
- **小禾（新手）**：网文爱好者转创作者，怕复杂，希望 10 秒建书、今天能写出正文。
- **老赵（老手）**：有完结作品，时间紧，讨厌流程绑架，要最快到达正文。
- **AI 用户（PRO）**：愿意用 AI 辅助生成，接受按流程配置设定与大纲。

## 2. 版本与功能边界

| 能力 | 免费 | PRO |
| --- | --- | --- |
| 创建小说 / 卷·章树增删改 / 直接写正文 / 自动保存 / 版本历史 / 归档 / 字数 | ✅ | ✅ |
| 卷配置 / 章配置（**摘要级**：卷名+卷摘要 / 章名+章摘要） | ✅ | ✅ |

| 专注模式 / 字号行距 / 写作进度 | ✅ | ✅ |

## 3. 核心流程

### 3.1 免费主流程（无设定）
```
作品列表 → 创建（书名）→ 正文工作台
  → 左树管理卷/章（添加/编辑/删除）
  → 点卷节点 → 抽屉填卷摘要
  → 点章节点 → 抽屉填章摘要 → 去写正文
  → 直接写作（自动保存/字数）
  → 归档（只读可查看）
```

### 3.2 PRO 附加流程
```
同一工作台 + 小说栏「设定」入口（7 项基本信息，AI 字段）
  + 卷/章抽屉高级字段（结构模板/冲突/key_points/情绪…）
  + 工具栏「AI 生成正文」→ 提示词面板（组装/可编辑）→ 流式输出
```

## 4. 界面结构（定稿）

### 4.1 层级
```
应用栏（产品级）：爱小说 logo · 我的作品 · 设置
小说栏（小说级）：书名 · 类型 · [设定(PRO)] · [免费提示]
面包屑栏（定位）：第一卷：星海初航 / 第二章：跃迁
三栏 body：大纲树（左）· 正文（中）· 本章进度（右）
```

### 4.2 三栏职责
| 栏 | 内容 | 归属 |
| --- | --- | --- |
| 大纲树 | 卷→章结构、各章字数/归档状态、卷/章节点 hover「配置 →」 | 卷级/章级 |
| 正文 | 工具条（字号/行距/专注/版本历史/归档本章）+ 编辑器 + 状态栏（字数/保存） | 章级 |
| 本章进度 | 进度百分比 + 目标字数 | 章级 |

### 4.3 配置抽屉
- 点卷节点 → 卷配置抽屉（免费：卷名+卷摘要；PRO：+结构模板/核心冲突/情绪/信息差/冲突阶梯）
- 点章节点 → 章配置抽屉（免费：章名+章摘要；PRO：+方向输入/key_points/情感基调/钩子/目标字数）
- 抽屉互斥，可一键「去写正文」

## 5. 功能需求明细

### 5.1 小说栏（免费模式）
- 显示书名 + 类型。
- **不显示「设定」入口**；提示文案"免费模式 · 无需设定，直接写"。
- PRO 模式：显示「设定」入口（链到设定页）。

### 5.2 大纲树
- 卷/章节点显示：标题、字数、归档状态（📦 已归档/未归档）。
- 卷节点点击 → 卷配置抽屉；章节点点击 → 章配置抽屉（事件不冒泡、抽屉互斥）。
- 正文树只显示有正文的章节；归档章节点击进入只读查看。

### 5.3 正文编辑器
- contenteditable 直接编辑；自动保存（停止输入 1.5s → "已自动保存 ✓"）。
- 实时字数（底部状态栏）；工具条：字号 小/中/大、行距 紧凑/舒适/宽松、专注模式、版本历史、归档本章。
- 归档后：编辑器只读（contenteditable=false）+ 顶部提示条；归档状态同步到树/进度卡。

### 5.4 设定页（PRO）
- 6 项基本信息：题材（类型+说明）、简介（梗概+详细）、世界（地理/政治/规则）、风格（叙述视角）、伏笔、角色。
- 进度"设定 n/6"；AI 字段（核心卖点/目标读者/语言风格/节奏偏好/基调/禁忌/爽点等）不显示，标注属 PRO。

## 6. 信息呈现原则（去重）

| 信息 | 唯一位置 |
| --- | --- |
| 层级（作品/卷/章） | 面包屑栏 |
| 归档状态 | 大纲树节点 |
| 实时字数 + 保存状态 | 正文底部状态栏 |
| 写作进度 | 右侧本章进度卡（百分比+目标） |
| 卷/章配置入口 | 树节点 hover |
| 返回列表 | 应用栏「我的作品」 |

## 7. 非功能需求
- 桌面端优先（pywebview），1280×800 基准，无横向溢出。
- 状态语言统一（未填/进行中/已确认、保存三态），暖色体系（daisyUI）。
- 无障碍：键盘可达、焦点可见、对比度 WCAG AA。

## 8. 验收标准（免费主流程）
1. 创建（只填书名）→ 直接进入正文工作台。
2. 左树添加/编辑/删除卷、章；点节点弹抽屉填摘要。
3. 抽屉「去写正文」→ 编辑器可写、自动保存、字数更新。
4. 归档本章 → 编辑器只读可查看，树/进度卡状态同步。
5. 全程不出现设定入口与任何 AI 字段。
