# 功能标记矩阵：免费（人工写作） vs 付费（解锁 AI）

> 产品经理视角 · 2026-08-10
> 原则：**一套 UI，两种状态**。免费用户 = 完整人工写作能力；付费用户 = 同一界面 + AI 能力解锁。
> 两个状态的**工作台体验几乎一致**——差别只在 AI 入口的出现/可用性，不改变主界面与操作路径。

## 1. 两种模式定义

| 模式 | 目标用户 | 核心路径 |
| --- | --- | --- |
| **免费版（人工写作）** | 自己写的作家 | 建书 → 正文工作台（左侧卷/章树 + 编辑器）→ 归档；设定/大纲为「高级配置」可选项 |
| **付费版（解锁 AI）** | 订阅用户 | **同一工作台** + AI 能力解锁（AI 生成正文、设定/大纲作为 AI 上下文、提示词面板） |

无创建时二选一：所有人进入同一工作台；付费状态只决定 AI 能力是否可用。

## 2. 功能标记矩阵

图例：🔴 免费必需 · 🟡 免费可选（高级配置）· 🔵 付费 AI · ⚪ 通用

| 功能 | 标记 | 说明 |
| --- | --- | --- |
| 创建小说 | 🔴 | 所有人都要 |
| 卷/章树：添加、编辑、删除、重命名 | 🔴 | 免费核心：直接在树上管理结构 |
| 直接写正文（编辑器+自动保存） | 🔴 | 免费核心：建书后直接写，不经过前置流程 |
| 版本历史/恢复 | 🔴 | 免费安全网 |
| 归档（只读） | 🔴 | 免费收尾 |
| 字数统计 | 🔴 | 免费刚需 |
| 专注模式/字号行距 | 🟡 | 舒适性增强（免费可选） |
| 设定（题材/简介/世界/风格…） | 🔵 | **免费完全不显示入口，可跳过**；付费后出现，作为 AI 生成上下文 |
| 卷纲配置（结构模板/核心冲突/情绪…） | 🟡 | 高级配置：免费可只建卷名+摘要；付费供 AI 使用 |
| 章纲（key_points/情绪设计/钩子…） | 🟡 | 高级配置：免费可不填；付费 AI 生成需要 |
| 提示词组装 | 🔵 | 仅付费 AI 生成时出现 |
| AI 生成正文（流式） | 🔵 | 付费解锁 |
| 章节状态（待配章纲/已确认） | 🟡 | 两态一致，免费可忽略 |

## 3. 统一工作台设计（两态一致）

1. **主界面 = 正文工作台**：左侧卷/章树 + 右侧编辑器，建书后直接进入。
2. **设定/大纲 = 高级配置**：同一工作台内可展开（面板/抽屉），免费与付费都能进入，无强制门控。
3. **AI 能力按付费状态显隐**：付费用户在同一界面看到「AI 生成正文」等入口；免费用户看不到或显示 🔒 锁定提示。
4. **树即一切**：卷/章的添加、编辑、删除、重命名都在左侧树完成；正文树只显示有正文的章节。

## 4. AI 能力（付费）在同一工作台内

- 「AI 生成正文」按钮位于正文编辑器工具栏（付费可见/可用）。
- 点击后 AI 生成面板出现：提示词（由设定+章纲组装，可编辑）→ 确认生成 → 流式输出。
- 若设定/章纲未填：生成前引导"去高级配置补全设定/章纲"（不强制，可选择用现有内容生成）。

## 5. UI 标记建议

1. 创建后直接进入正文工作台（两态一致）。
2. 顶部/侧边提供「设定」「大纲」高级配置入口（可折叠面板，不占主流程）。
3. 付费能力入口统一带 🔒 或"PRO"标识：免费点击提示升级；付费直接使用。
4. 免费用户界面不出现提示词相关入口，付费用户也只在 AI 生成面板内看到。

## 6. 待确认

- 免费用户对"高级配置"的可见性：完全可见可进（不强制），还是折叠隐藏？（建议：可见可进，标注"高级配置，可选"）
