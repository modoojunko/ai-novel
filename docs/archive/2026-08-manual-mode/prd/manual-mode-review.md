# 产品经理走查：纯手动模式能否完整写出一本小说

> 目标：验证"用户不依赖 AI、一步步自己配置 + 手写"的路径是否闭环。
> 结论先行：**主流程完全闭环。提示词不属于手动写作流程——它是"AI 生成正文"能力的内部环节，手动用户全程不接触。**

## 1. 手动路径逐环节走查

| 环节 | 手动可用 | 说明 |
| --- | --- | --- |
| 创建小说 | ✅ | 输入书名即可，题材可不选先进 |
| 设定 7 项 | ✅ | 全部字段用户自填；题材配置/伏笔/角色标注"可后补"，不被卡死 |
| 大纲 · 卷 | ✅ | 手动建卷（卷名/摘要/初始章数）、写卷纲配置（结构模板/核心冲突/情绪/信息差/冲突阶梯/场景卡） |
| 大纲 · 章 | ✅ | 手动建章、逐章填章纲（方向输入/key_points/情绪设计/钩子/段落/字数） |
| **提示词** | ✅ 不出现 | 手动写作不经过提示词；提示词只在用户点击「AI 生成正文」时作为生成流程的内部步骤出现（组装 → 可编辑 → 生成） |
| 正文 | ✅ | contenteditable 直接手写，自动保存；AI 生成只是可选按钮 |
| 归档 | ✅ | 手动归档，归档后只读 |

## 2. 提示词的重新定位

**提示词 = AI 生成能力的内部环节，不是创作流程的一步。**
- 手动写作：从大纲确认后直接进入正文编辑器手写，全程不出现提示词。
- AI 生成（付费/可选）：用户点击「AI 生成正文」→ 弹出生成面板（由章纲自动组装提示词，Markdown 可编辑）→ 确认生成 → 正文流式输出。
- 提示词对纯手动用户零打扰，对 AI 用户是"生成前可查看/微调"的高级选项。

## 3. 手动模式验收标准

一条完整手动路径（不用 AI）：
1. 建书 → 进设定；
2. 7 项设定逐项填写并确认（可后补项跳过）→ 进入大纲；
3. 建卷 → 写卷纲配置 → 建章；
4. 逐章填章纲 → 确认；
5. 正文：直接手写 + 自动保存（**无提示词 UI**）；
6. 归档。

全程无任何一步强制调用 AI；AI 能力（生成正文/自动组装提示词）全部是**可选按钮**。

## 5. 优先级

| 事项 | 优先级 | 理由 |
| --- | --- | --- |
| 正文手写/自动保存 | 已具备 | — |
| 提示词移出主流程 | P0 | 手动用户零打扰 |
| AI 生成面板（组装提示词→可编辑→生成） | P0 | 提示词唯一出现位置 |

## 6. 范围确认

- 提示词编辑器（AI 生成面板内）先按 Markdown 纯文本编辑实现，不做复杂富文本。
