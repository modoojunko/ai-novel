# 用户故事地图：创建小说 → 设定 → 卷纲 → 章纲 → 正文

> 产品经理（PM）视角 · 2026-08-10
> 目标：把"从建书到写出第一章"的核心操作路径设计清楚，作为 UI/UX 高保真与后端设计的共同基线。

## 1. 地图总览（Backbone）

| 阶段 | 用户目标 | 关键动作 | 完成标志 |
| --- | --- | --- | --- |
| A. 创建小说 | 10 秒建好一本书 | 起书名 → 确认创建 | 作品出现在列表，进入正文工作台 |
| B. 写正文（主流程） | 直接开写 | 左侧卷/章树管理结构 → 编辑器手写（自动保存）；「设定」「大纲」为高级配置可随时打开 | 有正文产出 |
| C. 高级配置 · 设定 | 建立世界观与创作约束（可选） | 7 项设定逐项填写确认，或完全跳过 | 填写完成度自定 |
| D. 高级配置 · 大纲 | 搭骨架、让每章"写什么"明确（可选） | 左树点卷配卷/点章配章 | 至少 1 卷含章节 |
| E. AI 生成（PRO） | 由 AI 产出正文 | 工具栏「AI 生成正文」→ 提示词面板（组装/可编辑）→ 流式输出 | 生成完成 |
| F. 归档 | 收尾锁定 | 手动归档 → 只读 | 已归档章节 |

## 2. 用户画像

- **小禾（新手）**：27 岁网文爱好者，从未写完一本，怕复杂、怕"折腾半天没写出东西"。成功标准：今天能见到一段"像样"的正文。
- **老赵（老手）**：35 岁有完结作品，时间紧、功利，讨厌流程绑架。成功标准：最快到达正文，不被每一步都拦。

## 3. 分阶段用户故事与细节

### A. 创建小说

**故事 A1（新手）**：我想在 10 秒内建好书，并且知道接下来该做什么。
- AC：输入书名 → 回车创建 → 进入工作台「设定」tab → 顶部出现"设定进度 0/7"引导卡。

**故事 A2（老手）**：我不想每次建书都被引导打断。
- AC：引导卡可关闭，本次会话不再出现；建第二本书时默认弱化引导。

**痛点**：创建后直接进入空白工作台，新用户不知道从哪开始。

### B. 配置设定（7 项：简介 / 题材(+配置) / 世界 / 风格 / 反AI味 / 伏笔 / 角色）

**故事 B0（题材选择，第一步）**：我要选对题材，并知道它会影响什么。
- AC-1：题材列表按常见类型分组（玄幻/科幻/都市/悬疑…），支持搜索，选中即高亮。
- AC-2：选择题材后，后续表单加载对应参数模板（如科幻 → 世界观出现"科技水平/星际格局"参数；都市 → 出现"时代背景/社会规则"）。
- AC-3：已填的其他设定不因切换题材丢失；切换题材时明确提示影响范围（"将替换题材相关的参数模板，已填内容保留"）。
- AC-4（老手）：最近使用的题材置顶；题材可后改，但门控放行前建议确认。

**故事 B0.5（题材配置，跟随题材）**：我要按题材调好故事的"口味与边界"。
- AC-1：选中题材后出现题材配置表单，包含：基调蓝图（tone blueprint）、禁忌清单（taboos）、爽点类型（fulfillment types）、章节类型（chapter types）、节奏规则（pacing rules）、故事弧线模板（story arc templates）。
- AC-2：默认值由题材预置模板带入，用户可整体采用或逐项覆盖（config overrides）。
- AC-3：配置区可折叠，标注"高级项，可后补"——不强制填完才进入下一项。
- AC-4：切换题材时，已做的配置覆盖项保留并提示"与旧题材相关的模板已替换"。
- AC-5（老手）：可保存为自定义题材（is_preset=false），下次建书直接复用。

**故事 B1**：我要知道填到哪一步、每项为什么填、能不能后补。
- AC：顶部进度"设定 n/7"；每项卡片带状态（未填/进行中/已确认）；可后补项有标注。

**故事 B2**：我确认一项就要有即时反馈，失败要知道原因。
- AC：确认成功 → 卡片变绿 + 轻提示；失败 → 就地显示原因。

**故事 B3（老手）**：我不想被 7 项全卡住，想先写。
- AC：提供"先写起来"旁路（仍可创建卷/章），设定随时回来补。

**关键决策点**：题材是设定的**第一步与全局开关**——决定后续表单模板与参数范围，并自带一套**题材级配置**（基调/禁忌/爽点/节奏/弧线）；切换题材只换模板、不丢内容；题材配置是"默认带入、可覆盖、可后补"。简介可 AI 辅助（付费，阶段 2）。

### C. 配置卷纲

**故事 C1**：我要快速搭出"第一卷有哪几章"的骨架。
- AC：创建卷（名称+摘要）→ 卷内添加章节 → 保存成功有反馈。

**故事 C2**：卷纲完成后我要知道下一步。
- AC：出现「去配章纲」入口，切到章纲 tab 并聚焦第一个未确认章节。

### D. 配置章纲

**故事 D1**：我要知道每章缺什么、在哪确认。
- AC：章节卡片显示确认状态；未确认章节有「确认章纲」主按钮；缺必填字段时提示"缺：情感基调、必要变化"，点击跳转字段。

**故事 D2（老手）**：我要批量操作，不要逐章点开。
- AC：支持"确认全部已填章节"；已填字段就地可编辑。

### E. 写正文

**故事 E1**：我要舒服地长写，不怕丢。
- AC：自动保存 + 保存状态可见；字号/行距可调；专注模式。

**故事 E2**：我要知道写到哪了。
- AC：底部"本章 xx 字"；卷/章导航显示状态（草稿/进行中/已确认/已归档）。

## 4. 机会点与优先级

| 机会点 | 优先级 | 理由 |
| --- | --- | --- |
| 设定进度可视化 + 可后补标注 | P0 | 直接消解"7 项门槛"焦虑 |
| 每步完成出现下一步入口（闭环引导） | P0 | 用户永远知道去哪 |
| 章纲缺字段就地提示+跳转 | P0 | 阶段闸门顺畅度 |
| 正文排版控制+专注模式 | P1 | 长时写作体验 |
| 批量确认章纲 | P1 | 老手效率 |
| 创建后引导卡 | P0 | 新用户第一印象 |

## 5. 不做（范围护栏）

- 不做 AI 生成（阶段 2）
- 不做导入流程（另行设计）
- 不改变六阶段结构本身
- 后端不破坏现有文件存储（卷/章正文 YAML 保留），数据库只做元数据扩展
