## 0. 入口 IA（v2 终版：三处各司其职，词汇零冲突）

| 入口 | 位置 | 职责 | 按钮词 | 打开的界面 |

## 4. 视觉决策摘要（v6，给评审）

1. **设置是唯一的门**：备份/恢复的一切入口收敛到设置弹窗一行；书架与时机提醒层保持安静——「先备份 / 去恢复」都是跳设置的路标，不是第二扇门。
2. **弹窗即产品**：流程长在 440px wb-style Modal 里，进度步 locked 把「不可中断」画进结构；与设置弹窗同族外壳。
3. **进度语言零新组件**：serif 大百分比（--text-display 档）+ pill 四语气行内清单；备份与恢复同一套语气映射（S-R1）。
4. **敏感四层**：勾选时 warn（L1）→ 完成页钥匙 warn（L2）→ 文件名自标识（L3）→ 预览掩码 + 块级取消勾选（L4）；红全程不出场（除书架删除项按 N6 归位）。
5. **首启不打扰**：提示条形态让恢复引导「可见不强按」——空态本体原状、去恢复走设置、读不出来给三步救回并有出口；「知道了」随时关。
6. **双包恢复一步到位（v6）**：升级换机最常见动作是「两个文件一起拖」——Step1 一次接受 1-2 个 zip 省一次往返；预览按包分块、进度按块分段，块级勾选 / 完成叙事 / 智能挂回全不变；只拖一个按包类型单块渲染，不惩罚。
