四条设计原则（取自 PRD）

01

永远知道下一步

每屏至少一个明确的下一步入口；阶段完成即出现下一阶段入口。

02

状态可见

进度、保存、确认三种状态语言全局统一，完成即变色、即时反馈。

03

允许旁路

设定未完成也可以先写，不锁死用户；高级配置标注「可选，可后补」。

04

正文优先

桌面长时场景，信息密度适中；宋体排版、专注模式，低刺激。
