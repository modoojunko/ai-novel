拍板结果（2026-09-06）

  1. UI 方案：通过——seg 位置、厂商锁定规则、编辑态可改格式均确认。
  2. URL 不预填：拍板。选供应商、切格式均不改动 URL，用户照抄厂商文档自填；GLM 帮助小字「点击填入」是显式动作，保留。
  3. 卡面不露格式：拍板。配置卡维持现状，不显示 OpenAI / Anthropic 格式标识。
  4. 后端按格式调用：拍板。配置的接口格式决定大模型调用走 OpenAI 契约（chat/completions）还是 Anthropic 契约（/v1/messages），连接测试与模型拉取同口径。
  5. 降级探活：未反对，按默认执行——anthropic 格式 models 404 自动降级 max_tokens=1 探活。
  6. GLM 帮助小字：拍板删除——URL 照抄厂商文档自备，界面不提供地址文案与点击填入（本稿已同步移除）。
  7. thinking 参数与模型选择：拍板归属「书的 AI 设定」域，本变更不涉及；openai 格式请求携带 thinking=disabled 的现状保持原样。
