## 测试环境与约定

### 环境变量

```bash
# C端 backend
DEV_MODE=1 DATA_ROOT=./data uvicorn main:app --reload --host 127.0.0.1 --port 8000

# S端 local simulator
python server/local_server.py
```

### 数据隔离原则

- 每个测试/worker 创建独立用户 (`createTestUser` / `uid()`)
- 每个项目使用 `Date.now()` 后缀保证唯一性
- 通过 API 创建数据，通过 UI 验证行为
- 永不依赖种子用户或跨测试共享状态

### 测试命名惯例

- `e2e/` 目录下按功能域拆分 spec 文件
- 每个文件内按 `test.describe` 嵌套组织：`功能域 > 用户故事 > 具体场景`
- 测试标题中英文混合：关键操作用中文，技术细节用英文

## 附录：Playwright 配置建议

### workers: 1 的原因

当前 `fullyParallel: false, workers: 1` 是合理的:
- 所有测试在同一个 DEV_MODE 后端上运行
- 串行执行避免共享状态冲突
- 如果未来实现数据隔离（每 worker 独立数据库），可改为并行

### 推荐的 trace 策略

```typescript
// playwright.config.ts (当前配置)
trace: "on-first-retry",   // 一次重试失败后捕获 trace
screenshot: "only-on-failure",
```

### 未来优化方向

1. **数据完全隔离**: 每个 worker 使用独立数据库或 schema
2. **分片并行**: `--shard=1/4` 等分片策略
3. **API 数据工厂**: 封装 `setupProjectPage`, `setupChapterPage` 等 fixture
4. **CI 集成**: 自动 shard + trace 上传 + 增量测试
