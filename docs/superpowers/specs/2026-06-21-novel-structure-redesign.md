# AI Novel 结构重设计

> 将小说管理从"6 阶段状态机"改为"小说→卷→章→正文"层次结构
> 设计确认日期：2026-06-21

---

## 1. 核心概念

### 1.1 小说数据结构

```
小说 (Novel)
 ├── 基本信息：书名、简介、题材
 ├── 设定（世界设定、风格规则、角色、伏笔）
 └── 卷 (Volume)  — 故事单元
      ├── 卷名、卷纲（整卷故事弧）
      └── 章 (Chapter)  — 叙事单元
           ├── 章名、章纲（场景概要）
           └── 正文（小说文字）
```

### 1.2 阶段 ≠ 结构

**小说结构**是静态的层叠数据：小说→卷→章→正文。
**创作阶段**是动态的状态标签，挂在章节上：未开始 / 章纲 / 写作中 / 待修改 / 已完成。

两者是正交维度。去掉全局进度条和阶段锁。

### 1.3 无 AI 优先

所有核心功能不依赖 AI。AI 辅助是增强项，不侵入基础 UX。
用户可完整地创建、编辑、删除卷和章，写正文，管理设定——全部手动操作。

---

## 2. 布局

### 2.1 整体结构

```
┌─────────────────────────────────────────────────────┐
│  [小说名]    设定 | 正文 | 线索                  │  ← 顶部 Tab
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  左侧树  │              右侧内容面板                │
│          │                                          │
│          │    （根据选中节点动态切换）               │
│          │                                          │
├──────────┴──────────────────────────────────────────┤
│  底部（状态图例、版权等）                            │
└─────────────────────────────────────────────────────┘
```

- 抛弃子路由（`/settings` `/outline` `/write` 等），单一路由 `/project/:slug`
- 页面状态由左侧树选中节点 + 顶部 Tab 共同驱动
- 右侧面板整页切换（编辑器 ↔ 版本历史），不浮层

### 2.2 顶部 Tab

| Tab | 左侧树内容 | 右侧内容 |
|-----|-----------|---------|
| 📋 设定 | 设定目录（世界设定/风格/角色/伏笔/简介） | 选中项的编辑表单 |
| 📖 正文 | 卷 · 章树 | 选中卷 → 卷编辑器；选中章 → 章编辑器 |

> 🔗 线索 Tab 暂不实现，保留为后续扩展点。

## 3. 设定 Tab

### 3.1 左侧设定树

每个节点 hover 时右侧显示操作按钮：
- 设定分类（世界设定/风格/伏笔/简介）→ `✎`（编辑名称）
- 角色分类 → `✎`（编辑名称）+ `➕`（新增角色）
- 角色条目 → `✎`（编辑）+ `🗑`（删除）
- 伏笔条目标题 → `✎` + `🗑`
- 底部固定「＋ 新建角色」

```
⚙️ 设定目录
├── 🌍 世界设定             v6
├── 🎨 风格规则             v3
├── 👥 角色                 4个
│   ├── 林深（主角）
│   ├── 赵刚（配角）
│   └── 苏晚晴（关键人物）
├── 🎯 伏笔                 3条
└── 📝 小说简介             v2
```

- 每项独立版本号
- 角色展开为子树，点击进入角色编辑
- 底部「+ 新建角色」
- 所有设定项为纯文本编辑（textarea），不做富文本

### 3.2 版本

- 每个设定项独立版本
- 版本栏显示在编辑区顶部：v6 · 2026-06-21 14:32
- 「历史版本」→ 右侧切换到版本历史页
- 每次保存自动创建版本

## 4. 正文 Tab

### 4.1 左侧卷/章树

每个节点 hover 时右侧显示操作按钮：
- 卷节点 → `✎`（改卷名）+ `➕`（添加章节）+ `🗑`（删除卷）
- 章节点 → `✎`（改章名）+ `🗑`（删除章）
- 卷内「＋ 添加章节」固定在最后一行
- 底部「＋ 新建卷」

```
📖 卷 · 章
├── ▾ 第一卷 · 迷雾     3章
│   ├── ch-1 不速之客    ✓ 完成    3,280字
│   ├── ch-2 暗流涌动    ✎ 写作中  1,256字
│   ├── ch-3 深渊回望    纲
│   └── ＋ 添加章节
├── ▸ 第二卷 · 暗战     2章
├── ▸ 第三卷 · 终局     0章
└── ＋ 新建卷
```

- 每章行显示：序号、章名、状态标签、字数
- 卷展开/折叠
- hover 行显示操作按钮（改名、删除）
- 底部图例：● 完成 / ● 写作中 / ● 章纲 / ○ 空位

### 4.2 空状态

刚创建小说、无卷无章时：

- 左侧树：显示「暂无卷和章节」
- 右侧：居中空状态引导
  - 图标 + 标题 + 描述
  - 三个快捷入口卡片：创建第一卷 / 直接写第一章 / 先去设定
  - 建议顺序提示

### 4.3 卷编辑器（选中卷节点）

```
卷名: [第一卷 · 迷雾]
版本: v3 · 2026-06-20    [历史版本]

卷纲: [textarea]

章节列表:
⠿ 01  不速之客    3,280字  ✓ 完成
⠿ 02  暗流涌动    1,256字  ✎ 写作中
⠿ 03  深渊回望    —        纲

[＋ 添加章节]        [💾 保存卷]    [🗑 删除此卷]
```

- 卷名可编辑
- 卷纲 textarea
- 章节列表可拖拽排序
- 点击章名 → 切换到章编辑器
- 卷本身有版本

### 4.4 章编辑器（选中章节点）

```
章节: 第一卷 · ch-2 暗流涌动    状态: [写作中]    1,256字
版本: v4 · 2026-06-21 14:32     [📋 历史版本]    ⚠️ 未保存

章纲: [textarea - 这章要发生什么]

正文: [textarea - 小说正文，serif 字体]

[💾 保存 (v5)]    [预览阅读模式]
```

- 状态下拉：未开始 / 章纲 / 写作中 / 待修改 / 已完成
- 版本栏固定显示在编辑区顶部
- 每次保存自动创建版本

### 4.5 版本历史页（点击「历史版本」后切换）

```
← 返回编辑器

版本历史 · 第一卷 · ch-2 暗流涌动

| 版本 | 时间                | 备注                | 当前 |
|------|---------------------|--------------------|------|
| v4   | 2026-06-21 14:32   | 新增350字...       | 当前 |
| v3   | 2026-06-21 11:20   | 修改章纲           |      | [恢复到v3]
| v2   | 2026-06-20 22:15   | 续写800字          |      | [恢复到v2]
| v1   | 2026-06-20 19:03   | 首次创建           |      | [恢复到v1]

v4 → v3 差异:
  — 原: 林深在废弃工厂发现了一个打火机。
  + 新: 林深在废弃工厂发现关键物证——带有血迹的打火机。
```

- 版本表格列出所有版本
- hover 行出现「恢复到 vX」按钮
- 底部显示选中版本的 diff（增删对比）
- 左侧树不变，仅切换右侧面板内容

## 7. 后端 API 变更

### 7.1 新增

- `GET /projects/:id/tree` — 返回完整小说结构树（设定项+卷+章+状态）
- `GET /projects/:id/volumes/:vid/versions` — 卷版本历史
- `GET /projects/:id/chapters/:cid/versions` — 章版本历史
- `POST /projects/:id/chapters/:cid/versions/:vid/restore` — 恢复版本
- `GET /projects/:id/chapters/:cid/versions/:vid/diff` — 版本 diff

### 7.2 修改

- `POST /projects/:id/volumes` — 返回完整树
- `POST /projects/:id/chapters` — 返回完整树
- 现有章/卷的 `PUT` 接口改为创建版本

## 9. 主题

双主题切换，daisyUI `data-theme` 驱动，顶部栏加切换按钮：

### 9.1 深色主题（novelforge）

当前已有。暖棕底 + 琥珀色点缀，深夜书房氛围。

在 `tailwind.config.js` 的 daisyui.themes 数组中新增 parchment 主题配置，两套主题并列。
