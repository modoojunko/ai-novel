# S端 Web 页面设计

> AI Novel S端 的 Landing page + 用户管理页面，本地开发用 FastAPI 提供 API，静态 HTML/CSS/JS 做前端。

## 架构

```
静态文件 (server/static/) → 浏览器直接访问
API 后端 (server/local_server.py) → JSON API
```

- 前端零依赖（无框架、无构建工具）
- FastAPI 同时提供 API + 挂载静态文件
- 静态文件放在 `server/static/www/` 下

## 页面路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | Landing page | 产品介绍 + 下载链接 |
| `/login` | 登录 | 用户名 + 密码 |
| `/register` | 注册 | 用户名 + 密码 + 密保 |
| `/auth` | OAuth 授权 | 已有，不修改 |
| `/dashboard` | 我的账号（默认=我的套餐） | 登录后跳转 |
| `/dashboard/license` | 我的套餐 | 套餐信息 + 到期日 |
| `/dashboard/activate` | 激活新码 | 输入激活码 |
| `/dashboard/devices` | 我的设备 | 设备列表 + 解绑 |
| `/dashboard/account` | 账号信息 | 修改密码 + 密保 |
| `/admin` | 发码管理 | 已有，迁入新目录 |

## API 设计

现有 API（不动）：
```
POST /api/auth-page          OAuth 授权页
POST /api/authorize          OAuth 授权
GET  /api/check-auth         轮询授权结果
POST /api/generate_code      发码（管理员）
POST /api/query_codes        查码（管理员）
```

新增 API：
```
POST /api/register           注册（无激活码）
POST /api/login              登录 → 返回 session token
GET  /api/user/me            当前用户信息（套餐、到期日）
PUT  /api/user/password      修改密码
PUT  /api/user/security      修改密保问题
POST /api/license/activate   激活码 → 绑定到用户
GET  /api/license/my         我的所有激活码
GET  /api/device/my          我的设备列表
DELETE /api/device/{hash}    解绑设备
```

## 关键约束

1. **纯静态前端** — 不要 npm、不要 React、不要构建工具。纯 HTML + CSS + JS
2. **Hash 路由** — dashboard 内部用 `#/license`、`#/activate` 等切换内容
3. **Session 管理** — 登录后返回 token，存 localStorage，所有 API 请求带 `Authorization: Bearer <token>` header
4. **统一样式** — 简单写一个 `www/style.css`，所有页面共用
