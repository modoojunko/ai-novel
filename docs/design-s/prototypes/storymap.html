支付期分支一览（都从 B 等待支付出发）：余额不足/取消 = 同屏内嵌反馈（二维码仍有效可重扫）；拿码失败 = 下单失败页（未扣款可重试）；付了但核对不过 = 核对中页（无重试，防重复支付）；15 分钟不动 = 已过期（重新下单）。
