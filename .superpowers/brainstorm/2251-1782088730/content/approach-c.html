林深在废弃工厂发现关键物证，但被人抢先一步拿走。他在现场看到一串脚印——是自己的鞋码。

林深蹲下身，手指在地面上划出一道浅浅的痕迹。灰尘很厚——说明至少两周没人来过。但脚印是新的。

他掏出手机拍照，屏幕的光照亮了角落里的一个东西。烟头。他小心地捡起来，发现烟嘴上的牙印很深——这个人很紧张。

切换章纲 ✎ AI 续写 ▸ 质量检查 ◉
核心变化
  • 没有顶部 Tab 了 — 所有导航由左侧树驱动
  • 选章即写作 — 在树中点一个章，右侧直接展示章纲+正文编辑器
  • 设定和线索 — 作为树顶层的特殊节点，点开显示对应页面
  • 无阶段概念 — 每章独立的状态（未开始/章纲/写作中/已完成）显示在树节点上
  • 需要后端配合：在 API 返回中加入完整树结构

优点

  • 最符合作家思维——在结构树中找到位置，直接工作
  • 写作体验最好——选章、看章纲、写正文，同一页面完成
  • 彻底消除了「阶段」与「结构」的混淆

缺点

  • 需要后端返回完整树结构（新 API 或扩展现有）
  • 路由结构需要大改
  • 当前所有独立页面（OutlinesPage/PromptsPage/WritePage/ArchivesPage）需要合并
  • 改动量大，需要 2-3 天
