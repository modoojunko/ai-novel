# Design · c-home-redesign

## Context

现状 welcome 卡（方标 + 一行标题 + 两个按钮）被评「太丑」——素到不像设计过的。约束：设计语言不变（墨绿单强调色、宋体展示、token 体系）、不做产品介绍（用户已下载安装）、slogan 定稿「人铸灵魂，AI 行笔墨」。

## Goals / Non-Goals

**Goals**：给用户三个有明显气质差异、且都在设计语言内的方向，拍板后高质量落地。
**Non-Goals**：营销内容回流；书架三态（另批）；品牌最终定稿（本稿是给品牌 agent 的迭代基座）。

## 三变体设计说明（`docs/design-c/prototypes/home.html`）

| 变体 | 一句话 | 关键手法 |
| --- | --- | --- |
| a 玄墨 | 居中仪式感 | 48px 宋体两行主标（第二行墨绿）+ 44px 细线 + 顶部 7% 墨绿微光 + 逐级 fadeUp |
| b 卷首 | 书页卷首式 | 全页 18px 细框 + 左对齐编辑排版：竖线引导的 brand eyebrow、58px 带标点大字、通栏细线、按钮与注脚同行两端对齐 |
| c 朱印 | 扉页竖排式 | surface 卡片框 + 竖排双行 slogan（writing-mode: vertical-rl）+ 框下细线与横排辅助信息 |
| d 断章 | 海报级大字 | 左下压底、92px 断句大字（min(10.5vw)）+ 眉头小字「爱小说」+ 按钮注脚同行 |
| e 悬丝 | 中轴悬线极简 | 一线垂落 + 单行宽字距 slogan（0.22em、墨绿间隔点）+ 大留白 |
| f 对仗 | 左右分立 | 人/AI 两栏隔中缝细线对望、右栏墨绿——句意即版式；窄屏纵向堆叠 |

> 2026-08-29 评审修订：应用户反馈移除 hero 区独立「爱」字图标（A 的品牌方标、C 的斜印章）——顶栏 logo 已承载品牌记认，页面中景再放一个显得突兀。品牌图形收敛在 appbar logo。

共用：appbar（logo + 登录 + 免费开始）、页脚、CTA 组（免费开始/我已有账号 btn-lg）、免费口径注脚。

## Decisions

1. **三变体一文件**：`data-v` 路由 + 右下角切换器（非基线元素，同 `.rv` 先例），OpenDesign 直接渲染，评审零成本。
2. **slogan 排印差异即变体差异**：a 用 <br> 断行居中、b 带标点左对齐、c 竖排——同一句话三种气质，不新增文案。
3. **无新色新组件形态**：微光用 `color-mix(accent 7%)`（旧 hero 先例）；hero 区不放品牌图形（顶栏 logo 已承载），全部 token 派生。

## Risks / Trade-offs

- 竖排 Latin「AI」在 `text-orientation: mixed` 下整体横倒，是竖排排印惯例；若用户不接受，备选 upright 逐字母直立或改「人工智能」。
- 变体 b 的全页细框在窄窗口（<720px）会显得挤，落地实现时加窄屏退化为去框（原型评审以桌面为准）。
